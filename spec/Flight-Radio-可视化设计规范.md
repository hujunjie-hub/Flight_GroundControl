# 遥控器双摇杆实时监视设计规范

- 版本：1.2
- 日期：2026-11-14
- 状态：按用户反馈调整为简洁双摇杆示意图，等待 Windows x64 Release 本地验收
- 适用仓库：`hujunjie-hub/Flight_GroundControl`
- 页面：`src/FirmwarePlugin/Flight/FlightRadio.qml`
- 跟踪 Issue：[FGC-0045 遥控器双摇杆实时监视优化](https://github.com/hujunjie-hub/Flight_GroundControl/issues/45)
- 参考：用户提供的遥控器配置页面截图（2026-11-14）

## 1. 目标

保留原页面的深色调试面板和左右两个圆形摇杆示意图，不采用真实遥控器照片或写实机身插画。核心目标是在调试时，左右摇杆指示点能够跟随接收机上报的 RC 通道实时移动，使操作者能直观看到摇杆方向和幅度。

## 2. 页面结构

### 2.1 左侧校准区

保持现有内容和行为：

- 横滚、俯仰、偏航、油门通道行程显示。
- 开始校准、确认保存、取消、校准进度和提示。
- CRSF / ELRS 绑定。
- 复制微调量。
- 原有 Vehicle 状态、通道数和校准状态门控。

本轮不重构校准业务流程。

### 2.2 右侧实时摇杆区

按原截图保留：

1. 摇杆实时状态与通道数据接收提示。
2. 日本手 / 美国手 / 中国手选择。
3. 左、右两个圆形摇杆示意图。
4. 摇杆横向/纵向通道编号和 PWM 数值。
5. 通道监视器。

不绘制完整实体遥控器，不展示虚构的遥控器 LCD、天线、拨杆或品牌型号。

## 3. 双摇杆图形

- 资源：`resources/FlightStickGimbals.svg`
- 资源别名：`qrc:/res/FlightStickGimbals.svg`
- 画布：900 × 420，透明背景。
- 图形：左右各一个圆形云台，包含外圈、内圈、中心圈、横纵十字线和方向刻度。
- 保留深色底板、低对比度刻度和细边框；实时位置指示点采用淡黄色。
- 插画只负责静态刻度和圆环；实时摇杆点由 QML 绘制。
- 圆环按原始宽高比缩放，不裁切、不拉伸。

### 3.1 实时指示点

- 左右摇杆各有一个独立的 QML 指示点和柔和光晕。
- 指示点的位置由当前模式对应的两路 RC PWM 数据决定。
- 指示点可做短时缓动以降低帧间跳动，但不得自行摆动或在无数据时动画。
- 摇杆回中时指示点回到圆心；推到边缘时指示点按归一化数据向对应方向移动。
- 只有横向和纵向两个通道值都有效时才显示指示点。
- 无数据或 PWM 值不在有效接收范围时隐藏指示点，并在读数区显示“无信号”，不得用 1500 µs 假值填充。

### 3.2 归一化

沿用当前 PWM 归一化范围：

`fraction = clamp((PWM - 1000) / 1000, 0, 1)`

- 横向：0 为最左，0.5 为中心，1 为最右。
- 纵向：0 为最下，0.5 为中心，1 为最上。
- 仅将 800–2200 µs 作为有效接收值；超出该范围按无效数据处理。
- 指示点最大运动半径为云台示意图直径的 28%，保证点始终在内圈运动区域内。

## 4. 手型通道映射

沿用现有 `stickChannels` 定义，不因图形简化而改变通道语义：

| 模式 | 左摇杆（横向 / 纵向） | 右摇杆（横向 / 纵向） |
|---|---|---|
| 日本手 | CH4 / CH2 | CH1 / CH3 |
| 美国手 | CH4 / CH3 | CH1 / CH2 |
| 中国手 | CH1 / CH2 | CH4 / CH3 |

模式选择只改变显示通道映射，不向飞控发送控制指令。

## 5. 读数与通道监视器

- 左右摇杆下方分别显示当前横向、纵向通道编号和 PWM 值。
- 通道监视器继续显示收到的通道数量、各通道 PWM 数值和行程位置。
- 通道值无效时显示“无信号”，不把无效值画在摇杆边缘。
- “已收到 N 路通道”只表示收到了 RC_CHANNELS 数据，不等于接收链路健康或飞行安全。

## 6. 安全边界

- 本次只优化可视化和调试反馈，不改变 MAVLink 消息、Vehicle 解码、FlightRcMonitor 数据源和固件协议。
- 不新增遥控控制输出、模式切换、解锁或执行器控制动作。
- 不改变校准、保存、取消、绑定和复制微调量的原有命令与门控。
- MockLink 测试只能验证 GroundControl 的数据接收和 UI 更新，不代表真实接收机、飞控硬件或实际飞行验证通过。

## 7. 响应式要求

- 页面可用宽度 ≥ 1080 px：校准区和摇杆监视区两列布局。
- 页面可用宽度 < 1080 px：改为上下布局。
- 右侧摇杆图在 320–520 px 面板宽度内保持圆形和左右并列。
- 保留原有通道监视器的两列布局和深色工业风格。

## 8. UI 集成验收

新增/更新 `FlightRadioPageUITest`，通过 MockLink 注入 RC_CHANNELS，验证：

1. 原有左右双圆形示意图资源可加载。
2. 没有有效通道数据时，两个摇杆指示点隐藏。
3. 注入第一帧 RC_CHANNELS 后，左右指示点按美国手映射移动到对应位置。
4. 注入第二帧不同 PWM 值后，左右指示点再次移动，证明 UI 跟随实时通道更新而非停留在静态位置。
5. 通道读数显示真实 PWM 值。
6. 开始校准、保存、取消、绑定、复制微调量控件仍存在且保留原有启用条件。
7. 测试不触发校准、绑定、解锁或飞行控制命令。

Windows x64 MSVC Release、Unit、Integration、Installer、Clean Install 和 Installed Runtime 验收仍按项目总规范执行。未实际执行的门禁必须记录为 NOT_RUN。
